# Code of Conduct

## Our standards

Project spaces should remain useful and safe for contributors with different
backgrounds, abilities and levels of experience.

Expected behavior includes:

- discussing code and decisions without attacking people;
- giving specific, actionable feedback;
- respecting privacy and declining to repost private material;
- acknowledging mistakes and correcting them;
- making room for people who need more context or time.

Unacceptable behavior includes harassment, threats, sexualized attention,
discrimination, deliberate intimidation, publishing private information, or
using project infrastructure to target another person.

## Enforcement

Report conduct problems to the maintainers through a private GitHub channel. If
no private channel is available, open an issue asking for one without including
the incident details. Maintainers may edit or remove content, restrict
participation, block accounts, or refer platform abuse to GitHub.

Maintainers must handle reports with discretion and disclose information only
when required to investigate or protect affected people.
